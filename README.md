# Azure APIM Policies for Zed

Editor support for Azure API Management policy documents: XML with C# policy
expressions.

It has:

- highlighting via a custom Treesitter grammar including inline JSON and C#
- completions from a bundled language server
- hover context.

It doesn't have diagnostics

## File association

Files named `policy.xml` (the APIOps layout), `*.policy.xml` or `*.fragment.xml`
are recognised automatically. For other names, add globs to your Zed
`settings.json`:

```json
"file_types": {
  "APIM Policy": ["*-policy.xml", "**/apim/**/*.xml"]
}
```

## Building

```sh
scripts/build.sh
```

Dependencies:

- Rust
- Zed
